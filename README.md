# Ultima, Version by Version

A single-page timeline of every release of the single-player Ultima games (Akalabeth to Ultima IX,
plus the Underworld, Worlds of Ultima and Runes of Virtue spin-offs): original releases, ports,
Japanese and console versions, engine recreations, decompilation ports and fan remakes.

Open `index.html` in a browser. Everything (data, styles, script) is in that one file.
